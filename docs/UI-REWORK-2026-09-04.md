# UI foundation rework — September 4, 2026

This pass improves the existing interface before adding the proposed My League journey. It retains the dark league identity, red primary actions, gold emphasis, routes, season gates, and existing controls.

## Changes

- Shared page titles now separate page context from content, constrain long descriptions, and give actions a wrapping area.
- Shared card and section headings use the body typeface for easier reading. Oswald remains on page titles and key figures. Secondary text has stronger contrast, stat labels use sentence case, and interior dividers are quieter.
- Cards use solid surfaces instead of backdrop blur. Interactive cards respond through color and border changes without shifting position. Relative positioning preserves containment of the schedule's scrolling table.
- Explore groups the existing links under Play, Statistics, and League. Desktop and mobile share the same renderer, with the existing phase gates and mobile duplicate filtering preserved. Escape and route navigation retain their dismissal behavior.
- Statistics navigation forms a predictable two-column layout on phones and clearly outlines the selected destination. Admin section navigation emphasizes the current section without outlining every link.
- Mobile native form fields have a 44px minimum height; hidden fields, checkboxes, radios, sliders, color controls, and file pickers retain their existing geometry. Existing field focus outlines and iOS zoom prevention remain.
- Schedule fixtures stack team names on phones, allow long names to wrap, and separate the match details action. Desktop keeps its compact score row. This-week and calendar links have button styling.
- Empty states, table hover/focus feedback, keyboard focus defaults, and the footer separator use the same visual foundation. Statistics data-quality notices now use the existing gold token instead of an undefined warning token.

No schema, action handlers, authentication, scoring, draft rules, result import logic, season state, or production data changes are included. No additional dependency, network request, or client boundary was added. Reduced blur is a rendering simplification; no measured performance claim is made.

## Review and validation

A Chromium survey checked the current fixture at 390px and 1440px across 28 route families, including player/team/match details and all three admin routes. The signed-in login route redirects home by design. The scrim-history browser test separately opens a real completed scrim at both widths and checks its title and overflow. The signup suite exercises anonymous login. One schedule overflow found in the survey was fixed by explicitly positioning the card; the mobile recheck reports 390px content in a 390px viewport.

Passed: all 2,213 unit tests; all 95 unique browser workflow tests (50 mid-season, 35 signup/draft/inhouse, 10 postseason); the extended scrim-detail check; TypeScript; ESLint; production build; and git diff whitespace checks. The browser suites used their dedicated disposable SQLite databases, with external Discord/Steam/OpenDota credentials disabled. No production deployment was performed.

Coverage spans all 29 page route families:

| Area | Pages |
| --- | --- |
| Competition | Home, draft, teams, team detail, schedule, match detail |
| Players and account | Players, player detail, comparison, profile, login |
| League information | News, feature tour, leaders, hero meta, record book, recap, Hall of Fame, seasons, season detail |
| Side games | Fantasy, Pick’em, inhouse, inhouse history, scrims, scrim detail |
| Administration | Admin, admin activity, imported-game quality |

This is route and workflow coverage against synthetic data, not a claim that every possible permission, data combination, or external service was exhaustively tested.
